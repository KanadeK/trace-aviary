# Changelog

## v0.1.0

- Added deterministic parsing for plain text, JSONL, and Sentry-style exports.
- Added normalization for paths, timestamps, IDs, numbers, email addresses, and common secret shapes.
- Added explainable TF-IDF clustering, representative samples, common tokens, time buckets, and reproduction hypotheses.
- Added CLI, FastAPI web UI, deterministic 500-event sample data, release packaging, CI, Pages demo, and bilingual documentation.
